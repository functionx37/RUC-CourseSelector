# RUC Course Selector CLI

本项目是本地运行的 RUC 抢课脚本。它使用一个专用浏览器配置供用户手动登录、捕获用户手动发起选课时产生的完整提交体，管理待选课程，并实现自动抢课。

> ⚠️ 选课自动化可能违反学校规则，使用者需自行承担**一切风险**。

> 本项目**不会**保存密码，也**不会**上传会话、课程或请求统计数据。

> ⚠️ 请不要向任何人分享 `.data` 目录下的任何文件，也**不要将其提交到仓库**。

> 本项目应该在**时间优先（可选可退）**、即选即得的选课阶段进行使用。

## 安装与启动

> 运行环境要求已安装 Chrome 或 Edge

安装依赖与启动脚本：

```bash
uv sync
uv run main.py
```

启动后支持以下命令：

- `login`：启动一个专用浏览器。请手动登录教务系统并勾选“记住我”或类似选项，并在完成后回到终端按回车键。
- `choose`：启动同一浏览器。请进入选课界面，对目标课点击一次选课；即使余量不足也可生成完整请求。返回终端后确认保存。最多同时跟踪 5 门课程。
- `list`：每行显示一门目标课的名称、课程名、教师和教学班 ID。
- `delete <编号>`：删除 `list` 中对应编号的课程，例如 `delete 2`。
- `run`：在 07:00–23:00 的每五分钟边界前后 30 秒运行抢课任务。本项目将每秒检查一次每门追踪中课程是否有余量，如果有则发出抢课请求，直到成功选课或者用户手动停止。
- `exit`：停止并退出程序。
- `help`：查看帮助
